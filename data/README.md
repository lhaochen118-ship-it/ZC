# data/

Đặt ở đây:

- `data.txt`: nội dung tab **Data** của portal DataMate (không đọc được trên web).
- Hai file zip dữ liệu của ban tổ chức (train / public test).

Dữ liệu đã giải nén nằm ở Kaggle dataset public `nhatlong1103/zc-2026`:
`kaggle datasets download nhatlong1103/zc-2026 -p data/raw --unzip` (`data/raw/` bị `.gitignore`).
